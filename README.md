# LRTC_MusicEEG
This repository has the Matlab (.p codes) and data for one participant (subject 8 in article) related to journal article "Long-range correlations in alpha-band of electroencephalogram: a nonlinear embedding and detrended fluctuation analysis" published in Frontiers in Neuroinformatics 2026.

The data (Subject 8 in article) required to run the above codes can be downloaded from the below link
